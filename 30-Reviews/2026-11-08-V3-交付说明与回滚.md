# Super-Brain 3.0 交付说明与回滚手册（2026-11-08）

> 面向：大古老师（非技术背景）与后续接手会话。
> 原则：只交付真数据、可回滚、口令永不写进任何文档。

## 一、这次交付了什么

| 编号 | 交付物 | 说明 |
|---|---|---|
| 1 | 实时推送（SSE） | `GET /api/stream`，页面数据从"每 6 秒轮询"升级为"有事件立即到"；推送不可用时自动降级轮询，侧栏明确显示「实时推送 / 轮询模式 / 连接中断」 |
| 2 | 七个业务页面 | Agent 管理、任务中心、协作中心、知识图谱、记忆中心、系统监控、系统设置，全部接真实数据 |
| 3 | 搜索能力 | 任务按 ID/类型/结果搜索；知识按标题/路径/标签/正文搜索，并支持分类筛选 |
| 4 | 任务进度自学习 | 用同类任务最近 20 次完成耗时的中位数估算，样本越多越准，封顶 95%，无样本不显示 |
| 5 | 设置页管理入口 | 启用/停用/新增 Agent，必须临时输入指挥口令 + 二次确认，口令不保存、不回显，后端留痕 |
| 6 | 首页 3D 协作网络 | WebGL 星空星云、7 入口内环 + 7 执行者外环、预生成通道（空闲半透明、执行中流动光点）、拖拽旋转 / 缩放 / 点击看详情；无 WebGL 自动降级 2D |
| 7 | 文档 | 本文件 + `70-Console/design/API-Contract.md`（API 契约与实测数据） |

## 二、怎么验收（3 分钟）

1. 浏览器直接打开 **`http://8.218.106.225:18765/`**（自动跳转到控制台；页面由 API 服务托管，无需另起静态服务）。
   本地预览也可以用：`cd 70-Console/design && python3 -m http.server 8974`，然后打开 `http://127.0.0.1:8974/prototype/index.html`。
2. 点击「接入真实数据」，粘贴**控制台只读口令**（存在服务器 `90-System/runtime/api_tokens.json` 的 `viewers.console`，只在本机浏览器保存）。
3. 应看到：
   - 侧栏顶部显示「实时推送」；
   - 首页 14 个 Agent、协作连线为实线（空闲时半透明，不发光）；鼠标拖动画布可旋转整个 3D 网络，滚轮/双指缩放，点击节点看详情；
   - 七个页面都有真实内容，任务页可筛选/搜索/点开详情；
   - 没有数据的地方显示「暂无数据」，不出现编造的百分比或健康分。
4. 断开方式：设置页「断开并清除口令」，或点击侧栏连接按钮。

## 四、部署说明

```bash
# 本地（/workspace/super-brain）
git add -A && git commit -m "..." && git push

# 服务器
cd /root/super-brain
tar czf /root/backups/v3-$(date +%Y%m%d-%H%M%S).tgz --exclude=.git .
git pull --rebase --autostash
systemctl restart super-brain.service
systemctl is-active super-brain.service
curl -s http://127.0.0.1:18765/healthz
```

本次部署记录：服务器 `/root/super-brain`，HEAD `142e013`，服务 `active`。

## 五、回滚方案（按影响面从小到大）

1. **只回滚前端页面**：`git checkout <上一个提交> -- 70-Console/design/prototype/`，无需重启服务（纯静态文件）。
2. **回滚后端**：`git checkout <上一个提交> -- 90-System/runtime/api_server.py 90-System/runtime/console_api.py && systemctl restart super-brain.service`。
3. **整体回滚到 2.0**：`git checkout v2.0-pre-console -- . && systemctl restart super-brain.service`（回滚点 tag 已在仓库）。
4. **灾难恢复**：解压最近备份 `/root/backups/v3-*.tgz` 到 `/root/super-brain` 后重启。
5. 回滚后验证：`/healthz` 200、`/api/overview` 200、`/cmd` 旧指令可用（指挥口令）。

数据库结构本次**未改动**，无需迁移或回滚数据库。

## 六、已完成 / 未完成清单

### 已完成

- 阶段 1 审计、阶段 2 设计系统、阶段 3 高保真原型（首页 + 七页真实页面）
- 阶段 4 首页真实数据 + SSE 实时推送
- 阶段 5 七个业务页面（含搜索、筛选、详情、进度条、空态）
- 阶段 6 集成：事件去重与顺序、断线重连与降级、权限隔离、错误态、CORS、连接数上限
- 阶段 7 测试与交付：渲染测试 22/22、接口/权限/性能实测、部署与回滚手册
- 控制台页面由 API 服务直接托管：打开 `http://8.218.106.225:18765/` 即可，无需另起静态服务

### 未完成 / 如实限制

1. 明文 HTTP，无 HTTPS；公网使用前应加反向代理与 TLS。
2. 无 IP 级限流；SSE 并发上限 8，单连接 10 分钟自动重连。
3. "历史回放"按钮仍为占位（未接真实回放数据）。
4. Agent 协作状态只有 `active/idle` 两态，没有更细的"等待/交接"状态（后端暂无可信数据源）。
5. 记忆页只读展示，尚不支持编辑/合并（需后端权限与审计设计）。
6. 首页 3D 需要浏览器支持 WebGL（现代 Chrome/Edge/Safari 默认支持）；不支持时自动降级为 2D 网络，并在画布下方提示。
