## C. 需要大古决定

1. **明文凭据**：`部署完成报告.md` 有服务器登录凭据；两篇 10-Knowledge/Playbooks 含疑似第三方账号凭据。轮换、Git 历史清除、改为口令包引用都要你批准，并指定执行人。
2. U1 规范与映射表是否批准；批准后先迁哪一批。
3. 是否单列「方法页」。
4. 个人备忘是否单开私密命名空间、是否退出 kb_search 检索范围。
5. 心跳丢失告警是否停止写入 60-Outputs/chat（runtime 改动）。
6. kb_search 的检索范围是否收窄到 Git 跟踪文件（runtime 改动，属 P2 生产变更）。
7. P2 / P3 是否立项（可能新增依赖、进程或费用）。
8. `projects.EDITORS` 含 grok-chief：是否在代码层禁止施工方给自己的阶段验收。
9. 是否给 GitHub `main` 开分支保护（要求 PR）；注意服务器每 30 分钟 `sync.sh` 直推 main，开保护前要先改同步方式。
