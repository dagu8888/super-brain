# 同步规则（所有 Agent 必须遵守）

## 原则

云端仓库是唯一信息源；本地只是工作副本。禁止任何 Agent 在本地独立保存核心知识。

## 三条硬规则

1. **写前先拉**：开始写入前执行一次 `git pull --rebase --autostash`（sync.sh 已内置）。
2. **写后即推**：写完立即执行 `bash 90-System/sync/sync.sh`。
3. **分区写入**：每个 Agent 只创建/追加自己署名的文件（`YYYY-MM-DD-主题-名字.md`），不修改、不覆盖别人的文件。需要补充就用 `[[]]` 双链引用。

## 冲突处理

- sync.sh 使用 `--rebase --autostash`，绝大多数情况自动合并成功。
- 因遵守"分区写入"，同一文件被两人改的情况极少；真出现冲突时：**保留双方内容**，按追加方式合并，绝不用 `--force`。

## 目录写入速查

| 内容 | 写到哪 |
|---|---|
| 还没分类的任何东西 | `00-Inbox/` |
| 复盘 | `30-Reviews/` |
| 新技能 | `20-Skills/` |
| 沉淀后的知识 | `10-Knowledge/`（Concepts / Playbooks / Decisions） |
| 任务执行成果 | `60-Outputs/YYYY-MM-DD/` |
| 图片/录音/文件 | `70-Assets/` |
| 事件日志 | `50-Events/`（只追加） |
