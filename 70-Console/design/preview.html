按钮

按压回弹 120ms scale(0.97)；主按钮仅用于每屏最关键操作。

卡片与玻璃材质

悬停上浮 -2px；玻璃在彩色背景上呈现 24px 模糊 + 180% 饱和，不支持时自动降级为高不透明底。

基础卡片

静态内容容器，圆角 20px。

可交互卡片

鼠标悬停时轻微上浮并加深阴影。

玻璃面板

用于顶栏、侧栏、浮动详情面板等层级更高的表面。

状态徽章

圆点 + 文字 + 颜色三重表达，不单独依赖颜色（可访问性要求）。

Agent 状态（7 种）

空闲 执行中 协作中 等待中 已完成 异常 离线

Task 状态（8 种）

待派发 已分配 执行中 受阻 等待中 已完成 失败 已取消

Agent 节点

指挥中心核心组件。单击选中（蓝边高亮），右侧打开详情面板。头像字母仅为演示，生产使用稳定 Agent ID。

动效与降级

四档时长（120/200/300/450ms）+ 统一缓动 cubic-bezier(0.2,0,0,1)；系统开启「减少动态效果」时全部动画自动关闭。

  • 悬停卡片 / Agent 节点：上浮 2–3px + 阴影加深（200ms）
  • 按钮按压：scale(0.97)，120ms 回弹
  • 详情面板：右侧 380px 平滑滑入（300ms）
  • 骨架屏 shimmer：仅加载期间出现，数据到达即替换
  • 协作连线流动动画：仅在真实协作事件活动期间触发，平时静态
