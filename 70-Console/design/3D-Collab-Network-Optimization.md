# 首页「Agent 协作网络」3D 优化方案（2026-11-08）

> 目标：从"固定环 + 静态图"升级为**状态驱动、自适应、可下钻**的指挥视图。
> 原则：真实数据驱动；不在线/空闲/工作中视觉分级；不重置用户视角；移动端可用。

## 一、现状问题（用户反馈归因）

| 问题 | 现状 | 原因 |
|---|---|---|
| 适配不智能 | 内环 7 入口 / 外环 7 执行者写死 | 位置按 kind 固定，不随在线/忙碌状态变化 |
| 状态无差异 | 只在颜色上略有区别 | 空闲、工作中、离线同样大小、同样透明度、同样居中 |
| 不能全屏 | 卡片固定 460px | 无"只看网络"模式 |
| 人员固定 | 刷新时整体 refresh，但布局不变 | 无动态增删与淡入淡出 |
| 不能看概况 | 只能点开右侧面板 | 无 hover 浮层 |
| 不能下钻 | 点击仅选中 | 无"进入该 Agent 场景" |
| 不智能 | 数量变化时半径不变，易重叠 | 无数量/视口自适应布局 |

## 二、布局引擎（状态分层）

三圈结构，按**实时状态**而非身份分圈：

| 层 | 状态 | 半径 | 视觉 |
|---|---|---|---|
| 内核 | working（工作中） | 1.8 ~ 2.6，按数量自适应 | 100% 不透明、最大尺寸、脉冲光晕、优先靠前 |
| 中环 | idle（空闲） | 3.6 ~ 4.6 | 55% 不透明、无光晕、尺寸 85% |
| 外缘 | offline（离线） | 5.6 ~ 7.0（贴近视口边缘） | 12% 不透明、灰化、尺寸 65%，几乎"隐入边缘" |

规则：
1. **半径自适应**：`r = base + max(0, n - 8) * 0.12`，同层均匀分布 + 轻微纵向错落，避免重叠。
2. **动态增删**：数据刷新做 diff；新节点从透明度 0 淡入并落到对应圈层；下线节点淡出后销毁，动画期间不重置相机。
3. **不在线推到边缘并隐藏**：`offline` 圈层半径贴边、透明度 0.12，鼠标悬停才恢复 0.55（可发现但不干扰）。
4. **相机自适应**：根据节点包围半径与视口宽高比计算 `fitDist`（竖屏自动拉远），容器变化时重算；用户缩放后保留用户倍率。
5. **标签密度**：窄屏或节点多时只显示首字母，全屏/宽屏显示全名。

## 三、全屏模式（只看网络）

- 卡片标题栏新增「⛶ 全屏」按钮；点击后卡片 fixed 铺满视口（`100dvh`），其余页面内容被覆盖，不销毁任何状态。
- 全屏内显示「退出全屏」按钮，`Esc` 同样退出；退出后视角、选中状态原样保留。
- 全屏时自动重算 fitDist 并放大标签，移动端可横竖屏使用。

## 四、悬浮概况（hover）

- 桌面：鼠标悬停 120ms 后出现浮层，跟随光标并自动避让边缘。
- 内容：名称 / 角色 / 类型 / 状态 / 当前任务（含进度原文）/ 最近活动 / 「点击进入场景」提示。
- 移动端：无 hover，改为点击进入场景，HUD 以底部卡片呈现。

## 五、点击下钻：Agent 场景

点击节点进入**聚焦场景**（非简单弹窗）：

1. 相机平滑飞向该节点，其余节点降至 12% 透明度，相关通道保留高亮。
2. 节点周围出现一圈细轨道光效，表示"当前场景"。
3. 左下 HUD 展示：状态、当前任务、进度条（从真实 `currentTask` 文本解析 %）、最近任务（调用 `GET /api/agents/{id}` 的 `recent_tasks`，真实数据）、协作通道数。
4. 「查看完整详情」打开既有右侧详情面板；「返回全景」或 `Esc` 退出，相机平滑回位。
5. 聚焦期间暂停自动旋转，拖拽仍可小范围环绕；滚轮可拉近拉远。

## 六、适配与性能

- 像素比：桌面 ≤2，移动端 ≤1.5；星数桌面 1400 / 移动 650；页面不可见时暂停渲染。
- 纹理按「状态 + 首字母 + 名称」生成，节点复用，不随刷新重建。
- 数据刷新只做 diff（位置/透明度/连线增删），不重建场景、不重置视角。
- `prefers-reduced-motion`：关闭自动旋转、缩短过渡。
- WebGL 不可用时保持 2D 降级链路（已验证无报错）。

## 七、三次迭代与验收

| 迭代 | 内容 | 验收标准 |
|---|---|---|
| 第 1 次 | 状态分层布局 + 动态增删 diff + 相机自适应 fit + 全屏 | 工作中节点在内圈且最大；空闲半透明中环；离线贴边近乎隐藏；增删节点有淡入淡出；全屏只显示网络，Esc 退出 |
| 第 2 次 | hover 概况浮层 + 点击聚焦场景 + HUD（含真实 recent_tasks） | 悬停出概况并避让边缘；点击后相机飞向节点、其余淡化；HUD 展示任务进度与最近任务；Esc 回全景 |
| 第 3 次 | 动效与性能打磨 + 移动端 + 键盘 + 回归 | 拖拽/缩放/聚焦过渡顺滑；移动端竖屏全部节点在视野内；Esc/返回一致；无 JS 报错；接口与权限不受影响 |

## 八、回滚

- 前端纯静态资源，回滚只需 `git revert` 对应提交并 `systemctl restart super-brain`。
- 3D 失败自动降级 2D；可临时给 URL 加 `?flat=1` 强制 2D（已实现）。

## 十、三层指挥框架（2026-11-08 追加，已上线）

### 10.1 结构

| 层 | 内容 | 位置 |
|---|---|---|
| 顶层 | 幕僚长（TRAE） | 中轴最高点，节点最大、紫色光环 |
| 中层 | 任务调度中枢（虚拟节点，非 Agent） | 中轴，青色，实时显示「待派 / 执行中 / 待批示」 |
| 底层 | 7 个执行者 + 6 个非幕僚长入口（DSH/DSH2/MAUS/MAUS2/Grok/DeepSeek） | 下层圆环 |

连线：幕僚长 → 调度中枢 → 每个执行节点（细线，空闲 6% 透明度）；真实历史派发仍按紫色委派线绘制；`default_route` 虚线不再重复画，由中枢连线表达。

### 10.2 每个节点的四项状态（全部真实字段）

| 状态 | 判定 | 展示 |
|---|---|---|
| 是否接入过 | `agents.last_seen IS NOT NULL` | 已接入 / 未接入 |
| 当前是否在线 | worker：`last_seen` 300 秒内；chief：入口身份不判离线，展示在线/久未使用 | 在线 / 离线 / 久未使用 |
| 是否空闲 | 无 `doing` 任务 | 工作中 / 空闲 / 调度中 |
| 关键决策待批示 | 该入口名下 `pending + priority≥1` 任务数 | 无待批示 / 待批示 N（红色角标） |

### 10.3 自适应规则

- 工作中 → 内圈（r=3.6）、满亮、放大；空闲 → 中环（r=5.9）、50% 透明；离线 → 外缘（r=8.4）、下沉、10% 透明，几乎隐入背景。
- 人员增减走 diff：新节点淡入、消失节点淡出，不重建场景、不重置视角。
- 队列数字变化时中枢节点贴图自动重绘；真实数据每 6 秒刷新一次。
