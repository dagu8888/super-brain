# 回写检查清单

## 每次回写后（逐条过）
- [ ] 走了 `writeback.ps1`，不是手工裸建文件
- [ ] frontmatter 七件套齐全：id / title / created / updated / source / tags / status
- [ ] `related` 至少 1 条双链（无关联则默认 [[MOC-总索引]]）
- [ ] 目录落位符合 [[README|README 落位表]]
- [ ] `sync.ps1` 输出末尾出现 `PUSH=OK`
- [ ] `git log origin/main -1` 能看到该提交（或 GitHub 网页可见）
- [ ] 重要结论已同步进 Agent 长期记忆（memory_save）
