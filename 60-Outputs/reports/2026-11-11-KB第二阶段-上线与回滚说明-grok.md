# KB 第二阶段上线与回滚说明（grok-chief，2026-11-11，北京时间）

## 上线了什么

| 项 | 内容 | 开关 / 位置 |
|---|---|---|
| 检索 | kb_search 只扫 git 跟踪的 .md（不再扫 12 万个队列文件和 50-Events）；默认引擎 hybrid（FTS5+二元组+实体+时效权重+拒答） | `kb_config.json` → `search.engine`：legacy / hybrid / shadow |
| 遮蔽 | kb_search 摘要、kb_read 正文统一遮蔽口令/激活码/令牌；15-Private/ 不对 Agent 开放 | `redact.patterns`、`search.read_deny_prefixes` |
| 心跳 | 不再生成 heartbeat_lost 事件和「心跳丢失」对话页；在线⇄离线翻转推一条提示给大古，单节点 30 分钟限频，重启后 15 分钟内静默 | `presence.*` |
| 入库闸门 | inbox-triage 只写 `10-Knowledge/_staging/` 草稿并推「待审草稿」提示；kb_promote / kb_reject 只有审批人能用 | `intake.*`（approvers 名单） |
| 受保护目录 | Worker 写 40-Agents/、90-System/ 一律拒绝；定时同步不再自动提交这两个目录 | `protect.*`、`90-System/sync/sync.sh`（`SYNC_PROTECTED`） |
| 周体检 | 每周一 09:00 跑 kb_lint，报告写 60-Outputs/kb-lint/，涉及编译层的重复页出合并草稿到暂存区 | crontab；`lint.*` |

## 回滚

1. **只回滚检索**：把 `90-System/runtime/kb_config.json` 里 `search.engine` 改成 `legacy`，然后 `systemctl restart super-brain`（配置按 mtime 热加载，新请求即生效，重启只为保险）。
2. **整体回滚代码**：`git revert -m 1 300d372 22a7357 67c586d d9df4c6`（四个合并提交，按倒序），然后重启、查 `curl localhost:18765/healthz`。
3. **恢复数据**：`/root/backups/super-brain-20261111-2051-pre-kbannex2.tgz`（仓库，排除 queue）、`/root/backups/state-20261111-2051-pre-kbannex2.db`（state.db 快照）、`heartbeat-pages-*.tgz`（被删的 159 篇心跳页）、`kb-B1-test-residue-*.tgz`（4 篇测试残留）。
4. **关掉闸门**：`intake.gate` 改 false，恢复 inbox-triage 直写 10-Knowledge。
5. **关掉在线提示**：`presence.enabled` 改 false（不会恢复旧的 heartbeat_lost 告警）。
